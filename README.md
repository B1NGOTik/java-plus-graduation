# API комментариев к событиям

---

## 🌐 Публичный API
### 1. Получить список опубликованных комментариев к событию
#### GET /events/{eventId}/comments
- Параметры запроса:
    - sort — вариант сортировки по дате публикации (`asc` и `desc`).
    - from — количество элементов, которые нужно пропустить (offset).
    - size — количество элементов в наборе (limit).
### 2. Получить один опубликованный комментарий по идентификатору
#### GET /events/{eventId}/comments/{commentId}

---

## 🔒 API зарегистрированных пользователей
### 1. Добавить комментарий к событию
#### POST /events/{eventId}/comments
- Параметры запроса:
    - userId - id пользователя, который оставляет комментарий
### 2. Получить список собственных комментариев
#### GET /users/{userId}/comments
- Параметры запроса:
    - eventId(опционально) — фильтр по событию.
    - from, size — пагинация.
    - sort — вариант сортировки по дате публикации (`asc` и `desc`).
### 3. Удалить свой комментарий
#### DELETE /users/{userId}/comments/{commentId}

---

## 👨‍💼 Admin API
### 1. Поиск и просмотр комментариев для модерации
#### GET /admin/comments
- Параметры запроса:
    - eventId (опционально) — фильтр по событию;
    - userId (опционально) — фильтр по автору комментария;
    - status (опционально) — статус публикации комментария (`PENDING`, `PUBLISHED`, `REJECTED`);
    - rangeStart, rangeEnd (опционально) — интервал по дате создания;
    - from, size — пагинация.
### 2. Модерация комментария (изменение статуса)
#### PATCH /admin/comments/{commentId}
- Параметры запроса:
    - status - новый статус комментария (`PUBLISHED`, `REJECTED`)
### 3. Удалить комментарий (например, за нарушение правил).
#### DELETE /admin/comments/{commentId}
